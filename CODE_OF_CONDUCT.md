# Code of conduct

This applies to everything under ttheme-project: issues, pull requests, reviews
and discussions.

Treat people with respect, and talk about the work, not the person. Harassment,
insults, hateful or sexual remarks and posting someone's private details are not
accepted. A maintainer may edit or remove such content and block the account that
posted it.

To report something, open the **...** menu on the comment, issue or pull request
and choose **Report content**. You can send it to the repository's maintainers
when that option is offered, or to GitHub Support. To report an account, choose
**Block or report** on its profile.
